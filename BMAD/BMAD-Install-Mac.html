BMAD Framework — macOS Installation Guide

Step-by-step setup for Mac. Uses the built-in Terminal app. Follow every step in order — each has a validation check so you know exactly when it's done.

Authors: Puneet Gaur  /  Nagaraj Yanambakkam  ·  Questions? See contact card at the bottom of this page.

🍎
macOS Edition This guide is for Mac users only. All commands are for the macOS Terminal (zsh/bash). If you are on Windows, use the separate Windows installation guide instead.

6
Verify Node.js Installation & PATH
After installing, open a new Terminal window so PATH changes take effect, then confirm Node.js is working.
2 min
Validate
Open a new Terminal window and validate all three Node.js tools

Why a new Terminal window?

macOS only registers new PATH entries in new Terminal windows. Always open a fresh window after installing any tool — otherwise commands run in the old window won't find the new installation.

  • 1
    Press Cmd + N to open a new Terminal window (or close and reopen Terminal entirely).
  • 2
    Run all three commands below — node (the runtime), npm (package manager), and npx (package runner). All three must respond with a version number:
% node -v
% npm -v
% npx --version
All three commands should return version numbers
yourname@Mac ~ % node -v v22.18.0 yourname@Mac ~ % npm -v 10.9.2 yourname@Mac ~ % npx --version 10.9.2
Any command shows "not found"? Add Node.js to PATH

Run this command to add Node.js to your PATH permanently, then open a new Terminal window:

Intel Mac:

echo 'export PATH="/usr/local/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc

Apple Silicon Mac (M1/M2/M3/M4):

echo 'export PATH="/opt/homebrew/bin:$PATH"' >> ~/.zshrc && source ~/.zshrc

Then run all three version commands again in the same window.

Success — node, npm, and npx are all ready ✓

node -v shows v20.x.x or higher, npm -v shows a version, and npx --version shows a version. All three are on your PATH. Move on to Phase 3.

Phase 3

Install Python 3.11+

Steps 7 – 9
7
Check if Python 3.11+ is Already Installed
BMAD requires Python 3.11 or newer — it uses tomllib, a built-in module added in Python 3.11. Older versions won't work. Let's check what you have.
1 min
Check
Run the Python version check
  • 1
    In Terminal, run:
% python3 --version
Terminal — possible outcomes
yourname@Mac ~ % python3 --version Python 3.11.9   ← Python 3.11+ installed. Skip to Phase 4! —— OR —— Python 3.9.7   ← Too old! Need 3.11+. Follow Steps 8–9. —— OR —— command not found: python3  ← Not installed. Follow Steps 8–9.

Do NOT use the plain "python" command on Mac

macOS ships with Python 2.7 built-in (the python command). Python 2 is incompatible with BMAD. Always use python3 to ensure you get the right version. BMAD requires Python 3.11+ because it relies on tomllib, which was added to the Python standard library in version 3.11.

Shows "Python 2.x" when you type python3?

On some older Macs, python3 may still return 2.x. Verify with python3 --version (not just python). If you still see Python 2.x, treat it as not installed and follow Steps 8–9.

Python 3.11 or higher installed? Skip to Phase 4!

If you see Python 3.11.x, 3.12.x, or higher — you're done. Jump to Phase 4 — UV.

What is UV?

UV is a fast Python package manager used by BMAD to run its internal scripts. Think of it as a smarter way to run Python scripts — it automatically picks the right Python version so you don't have to worry about it.

% uv --version
Terminal — two possible outcomes
yourname@Mac ~ % uv --version uv 0.7.3   ← UV IS installed. Skip to Phase 5! —— OR —— command not found: uv  ← Not installed. Follow Steps 11–12.
UV already installed? Move on to Phase 5!

Any version number means UV is ready. Move on to Phase 5 — Playwright.

What is Playwright?

Playwright is a browser automation framework used for end-to-end testing. It lets you write tests that control a real browser (Chromium, Firefox, or WebKit). BMAD's test architecture skills use Playwright to verify that your application works correctly from a user's perspective.

% playwright --version
Terminal — two possible outcomes
yourname@Mac ~ % playwright --version Version 1.x.x   ← Playwright IS installed. Skip to Phase 6! —— OR —— command not found: playwright  ← Not installed. Follow Steps 14–15.
Playwright already installed? Skip to Phase 6!

Any version number means Playwright is ready. Skip ahead to Phase 6 — Git.

14
Install Playwright via UV (only if missing)
Two commands are required — the first installs the Playwright Python package, the second downloads the browser binaries Playwright needs to run tests.
5–10 min
Install

Step 2 — Download Chromium browser binaries

Why a second command?

The first command installed the Playwright Python package, but Playwright also needs a real browser to automate. This second command downloads a pre-built Chromium binary (~150 MB) that Playwright controls during tests.

  • 3
    Run:
% playwright install chromium
  • 4
    Wait for the download to complete. This takes 2–5 minutes depending on your connection.

Phase 7

Install BMAD Framework

Steps 19 – 21
19
Navigate to Your BMAD Project Folder
BMAD must be installed from inside your project folder — it creates a _bmad/ directory there. Make sure you are in the right location before running the installer.
2 min
Setup
Navigate to your project folder in Terminal
  • A
    Option 1 — Use the cd command: Run the command below, replacing the path with the actual location of your BMAD project folder:
% cd ~/Desktop/BMAD_Project
  • B
    Option 2 — Use Finder: Navigate to your project folder in Finder → right-click the folder → select "New Terminal at Folder". A new Terminal window opens already inside that folder.
  • C
    Confirm you are in the right place:
% pwd

The output should show the path to your project folder (e.g. /Users/yourname/Desktop/BMAD_Project).

Why does location matter?

BMAD creates a _bmad/ directory inside whichever folder you run the installer from. This folder holds all the BMAD configuration, skills, and agent definitions for your project. Make sure you run the installer from your intended project root.

💡 macOS Tips to Remember

Always open a new Terminal window after installing PATH changes only take effect in newly opened Terminal windows. If a command says "not found" right after installing, open a fresh Terminal window and try again.
Apple Silicon vs Intel Macs M1, M2, M3, and M4 Macs (Apple Silicon) use /opt/homebrew/ for Homebrew tools. Older Intel Macs use /usr/local/bin. Commands are the same — only the installation path differs.
Typing passwords in Terminal When Terminal asks for your password (e.g. during installs), type it and press Enter — the cursor won't move and nothing will appear on screen. This is normal security behaviour. Your keystrokes are being recorded.
Homebrew makes everything easier Homebrew is the de facto package manager for Mac. If you don't have it yet, installing it from brew.sh will make future tool installations much simpler — just brew install <tool> for almost everything.
