BMAD Framework — Windows Installation Guide

Step-by-step setup for Windows machines using Command Prompt and Git Bash. Follow every step in order. Each step includes a validation check so you know it worked before moving on.

Authors: Puneet Gaur  /  Nagaraj Yanambakkam  ·  Questions? See the contact card at the bottom of this page.

What you will install

💚
Node.js
JavaScript runtime required for the BMAD CLI. Minimum: v20 LTS (v22 recommended).
🐍
Python
Required by BMAD internal scripts that read configuration. Minimum: Python 3.11.
⚡
UV
Fast Python package manager used by BMAD to run scripts. Any current version.
🎭
Playwright
Python browser automation framework for end-to-end testing. Installed via UV.
🔧
Git + Git Bash
Version control system. Git Bash is the shell BMAD uses on Windows. Any Git 2.x.
⚡
BMAD Framework
The AI-powered development methodology tool. Installed last, after all dependencies.

Validate & Install Node.js

    Step 3 — Close & Reopen Command Prompt

    After installing Node.js, close Command Prompt completely and open a new one. Windows only adds new programs to PATH when a new window is opened.

    3
    Verify Node.js is Working
    Confirm Node.js installed correctly and is on your system PATH.
    2 min
    Verify
    Open a new Command Prompt and run all three verification commands

    Why a new window?

    Windows only registers new PATH entries when a new Command Prompt is opened. Commands typed in the same window you used for installation will not find the new tools. Always open a fresh window after installing.

  • 1
    Press Win + R, type cmd, press Enter to open a fresh Command Prompt.
  • 2
    Run all three commands below — node (the runtime), npm (package manager), and npx (package runner). All three must respond with a version number:
    • C:\> node -v
    C:\> npm -v
    C:\> npx --version
    Expected output — all three commands succeed
    Command Prompt — new window
    C:\Users\you> node -v v22.18.0 C:\Users\you> npm -v 10.9.2 C:\Users\you> npx --version 10.9.2
    Any command not recognized? Fix the PATH manually

    If node, npm, or npx is not recognized after opening a new window — add Node.js to your system PATH:

    • Right-click Start → System → Advanced system settings → Environment Variables
    • Under System variables, find Path and click Edit
    • Click New and add: C:\Program Files\nodejs
    • Click OK on all dialogs, then open a new Command Prompt and run the three commands again
    Success — Node.js, npm, and npx are ready ✓

    node -v shows v20.x.x or higher, npm -v shows a version, and npx --version shows a version. All three are on your PATH. Move to Phase 2.

    Phase 2

    Validate & Install Python

    Steps 4 – 6
    4
    Check if Python 3.11+ is Already Installed
    BMAD scripts require Python 3.11 or newer. Older Python versions will cause errors.
    2 min
    Check
    Run the check command
  • 1
    In Command Prompt, run:
    • C:\> python --version
    Three possible outcomes
    C:\Users\you> python --version Python 3.11.9   ← 3.11+ installed. Skip to Phase 3! —— OR —— Python 3.9.7    ← Too old. Install Python 3.11 below. —— OR —— Python was not found  ← Not installed. Follow Steps 5 and 6.

    Why Python 3.11 specifically?

    BMAD uses a Python built-in module called tomllib to read configuration files. This module was added to Python in version 3.11. Older versions (3.9, 3.10, etc.) will cause BMAD scripts to fail with an import error.

    Already on 3.11+? Skip ahead!

    If the output shows Python 3.11.x or higher — Python is ready. Skip to Phase 3.

    Verify
    Open new Command Prompt and verify Python and pip
  • 1
    Close Command Prompt and open a new one: Win + R → cmd → Enter.
  • 2
    Run both commands below — python (the interpreter) and pip (the package installer). Both must show version numbers:
    • C:\> python --version
    C:\> pip --version

    C:\Users\you> python --version Python 3.11.9 C:\Users\you> pip --version pip 24.x.x from C:\...\Python311\lib\site-packages\pip (python 3.11)
    Any command not found? (Method B / python.org installs only)

    If you used Method B (python.org) and forgot the "Add Python to PATH" checkbox, fix it manually — add both paths to your Environment Variables. If you used Method A (Microsoft Store), this should not happen; try opening a new Command Prompt first.

    • Press Win + R, type sysdm.cpl, press Enter → Advanced tab → Environment Variables
    • Under User variables, find Path and click Edit
    • Click New and add: %LocalAppData%\Programs\Python\Python311\
    • Click New again and add: %LocalAppData%\Programs\Python\Python311\Scripts\
    • Click OK on all dialogs, open a new Command Prompt, and try again

    The Scripts\ path is where pip lives — both paths are required.

    What is UV?

    UV is a fast Python package manager used by BMAD to run its internal scripts. Any current version works. If uv --version shows any version number, you're done with this phase — skip to Phase 4.

    UV found? Move on to Phase 4!

    Option B — Via pip (Command Prompt, if Option A fails)

    Verify
    Open new window and test
  • 1

    Still not found? Fix UV PATH manually

    Phase 4

    Install Playwright

    Steps 10 – 12
    10
    Check if Playwright is Already Installed
    Playwright may already be present if you have used it before. Any version is compatible.
    1 min
    Check
    Run the check command

    What is Playwright?

    Playwright is a browser automation framework used for end-to-end testing. It lets you write tests that control a real browser (Chromium, Firefox, or WebKit). BMAD's test architecture skills use Playwright to verify that your application works correctly from a user's perspective.

    C:\> playwright --version
    Two possible outcomes
    C:\Users\you> playwright --version Version 1.x.x   ← Playwright IS installed. Skip to Phase 5! —— OR —— 'playwright' is not recognized  ← Not installed. Follow Steps 11 and 12.
    Playwright already installed? Skip ahead!

    Any version number means Playwright is installed. Skip to Phase 5 — Git.

    11
    Install Playwright via UV (only if missing)
    Two commands are required — the first installs the Playwright Python package, the second downloads the browser binaries Playwright needs to run tests.
    5–10 min
    Install
    Step 1 — Install the Playwright package via UV
  • 1
    Open Command Prompt (Win + R → cmd → Enter).
  • 2
    Run:
    • C:\> uv tool install playwright
  • 3
    Wait for UV to finish downloading and installing the package.
    • Command Prompt — UV installing Playwright
    C:\Users\you> uv tool install playwright Resolved 1 package in 0.5s Installed 1 package in 1.2s + playwright==1.x.x
    Step 2 — Download Chromium browser binaries

    Why a second command?

    The first command installed the Playwright Python package, but Playwright also needs a real browser to automate. This second command downloads a pre-built Chromium binary (~150 MB) that Playwright controls during tests.

  • 4
    Run:
    • C:\> playwright install chromium
  • 5
    Wait for the download to complete. This takes 2–5 minutes depending on your connection.
    • Command Prompt — downloading Chromium
    C:\Users\you> playwright install chromium Downloading Chromium 1xx.x.xxxx.x (playwright build vxxxx) from https://playwright.azureedge.net/... Chromium 1xx.x.xxxx.x (playwright build vxxxx) downloaded to: C:\Users\you\AppData\Local\ms-playwright\chromium-xxxx\

    Open new window and test

  • 2

    Still not found? Fix Playwright PATH manually

    UV tool installs may not update your PATH automatically. Try closing and reopening Command Prompt. If still missing, run uv tool update-shell in a new Command Prompt, then close and reopen again.

    💡 Tips for Windows Users

    Always open a new window after installing PATH changes only take effect in new Command Prompt / PowerShell / Git Bash windows. If a command isn't found, close and reopen the terminal first.
    Machine restart solves many issues If any command still fails after fixing the PATH, try restarting your machine entirely. A full restart guarantees all environment changes take effect.
    All tools here are free Node.js, Python, UV, Git, and BMAD are all free and widely used in professional software development.
    Git Bash is required for BMAD The BMAD installer and its scripts need Git Bash (not regular Command Prompt or PowerShell) on Windows. Always use Git Bash for BMAD commands.
