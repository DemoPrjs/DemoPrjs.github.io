The Cloud Blog — Day 2 Enhancement Guide

Step-by-step BMad agent execution for Puneet Gaur's Day 2 demo: 4 enhancements layered on top of TheCloud.html — Registration Modal, Contact Modal, Chatbot Widget, and AWS Tutorial section. All 6 agents in sequence, 45-minute window.

Day 2 Enhancements — 4 New Features Added to TheCloud.html

This playbook is additive. The existing TheCloud.html, prd.md, architecture.md, and ux-spec.md are all read by agents — no re-work from scratch. Each agent extends the Day 1 artifacts and the Dev Agent produces an enhanced TheCloudV2.html.

Enhancement 1

Registration Modal

Replace the inline registration section with a modal popup triggered by the nav Register button. Fields: Full Name, Email, Username, Password.

Enhancement 2

Contact Us Modal

Replace the inline contact section with a modal popup triggered by the nav Contact link. Fields: Name, Email, Subject, Message.

Enhancement 3

Chatbot Widget

Floating chat button at bottom-right. Expands into a chat window with a welcome message, input box, and structured hooks for future AWS Bedrock API connection.

Enhancement 4

AWS Tutorial Section

New dedicated section with a YouTube embed placeholder titled "AWS Basics for Beginners" and a short description, styled consistently with the portal theme.

How Enhancement Works in BMad — Reading Day 1 Artifacts From Disk

Step A

Agents read existing Day 1 files

Every agent starts by reading prd.md, architecture.md, ux-spec.md, and TheCloud.html from disk. No copy-paste. No regeneration of existing work.

Step B

Agents append, not replace

Each agent adds new sections to existing artifacts: prd-v2.md extends the PRD, new story files go into stories/, architecture-v2.md adds modal + chatbot design patterns.

Step C

Dev Agent enhances TheCloud.html

The Dev Agent reads all v2 artifacts plus the original TheCloud.html, applies the 4 enhancements surgically, and saves the result as TheCloudV2.html.

Tips for Day 2 Demo — Avoid Common Mistakes

Tell the Dev Agent to read TheCloud.html first The most common mistake is the agent generating a fresh portal instead of enhancing the existing one. The prompt above is explicit — but if it starts regenerating, interrupt immediately: "Stop — read TheCloud.html first."
Show the Bedrock comment to the audience Open DevTools → Sources → search "BEDROCK". Point to the comment and say: "This is where a Lambda call to AWS Bedrock replaces the dummy response. The BMad Dev Agent structured the code for future integration."
Confirm modals close via overlay click Both modal close paths (X button and overlay click) must work. Test both during QA — overlay click is the one most likely to be missing if the agent simplified the JS.
Show the YouTube embed comment View page source → search "YOUTUBE EMBED". The comment shows exactly where a real iframe goes. Tell the audience: "One line swap and the tutorial video plays in production."
If the Dev Agent runs over 10 minutes Type: "Please output TheCloudV2.html now with whatever enhancements are complete. Mark any unfinished enhancement with a <!-- TODO --> comment." This gets you an openable file fast.
Version comparison is the Day 2 talking point Open TheCloud.html and TheCloudV2.html side by side in two browser tabs. Show the audience what changed — modals instead of inline forms, chatbot in the corner, new tutorials section. The diff tells the BMad story visually.
